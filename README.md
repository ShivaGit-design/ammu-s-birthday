# 💙 AMMU UNIVERSE 2.0 🌙 — THE ULTIMATE CINEMATIC BIRTHDAY LOVE EXPERIENCE

> A theatrical, slide-by-slide cinematic love journey created especially for **PRITHI ("Ammu 💙🌝")** celebrating her birthday on **November 16**.

Built with React 19, TypeScript, Tailwind CSS, IndexedDB Local Media Persistence, Web Audio API, Canvas Confetti, and movie-grade animations.

## 📸 Media Uploads & Persistence (Zero Backend Required)

All media uploaded in the browser (photos, videos, songs) is **securely saved in the browser's IndexedDB**:
- **Coffee date photo**
- **First picture together**
- **Multiple memories gallery pictures**
- **Personal video clip**
- **Tamil romantic song**
- **Custom edited captions & messages**

They are stored locally on your device without size limits and **remain saved even if you refresh or reopen the website!**

---

## 🎵 Continuous Tamil Love Song & Ambient Player

- Upload your chosen Tamil romantic audio track (MP3 / WAV / M4A) on **Slide 7**.
- The song **plays continuously across all slides** without restarting or cutting out when navigating between scenes.
- A floating player in the bottom-left is accessible from every slide to toggle play, pause, mute, or adjust volume.
- If no custom MP3 is uploaded, a dreamy, synthesized romantic piano melody plays automatically.

---

## 🎮 Cinematic Navigation Controls

- **Desktop**: Use the **Right Arrow** or **Spacebar** to advance to the next scene; use the **Left Arrow** to go back.
- **Mobile & Tablets**: Swipe left or right anywhere on the screen.
- **Scene Menu**: Tap the **"Scenes"** button in the top navigation bar to open the chapter drawer and jump directly to any scene.
- **Progress Bar**: A slim illuminated progress bar at the top reflects the exact journey from Scene 01 to 11.

## 🚀 How to Run Locally

1. Open your terminal in `b:\Birthday`.
2. Start the development server:
   ```bash
   cmd /c npm run dev
   ```
3. Open your browser at `http://localhost:5173`.

## 📤 Publishing & Sharing with PRITHI

### Option 1: Vercel (1-Minute Deploy)
```bash
cmd /c npx vercel
```
Follow the short terminal prompts to receive a public URL (e.g., `https://for-ammu.vercel.app`).

### Option 2: Netlify Drop
1. Run `cmd /c npm run build`.
2. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
3. Drag and drop the `b:\Birthday\dist` folder onto the page to get an instant live link.
